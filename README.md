# Зміст: дані гри / Zmist: game data

Тут публікуються файли даних денної гри-вгадайки «Зміст» (словник, таблиця форм слів, слова для стіни літер, місця слів за днями). Файли з'являться тут разом з першим публічним випуском застосунку; пакети слів публікуються для днів, що вже минули.

The data files of the daily Ukrainian word-guessing game «Зміст» (dictionary, word-form table, wall words, per-day ranking packs) are published here. They are added with the first public release of the app; ranking packs are published for days that have already passed.
